# Support Ticket System

This project demonstrates a Databricks App backed by Lakebase.

## Features

- View support tickets
- View ticket messages
- Create new ticket
- Add messages
- Update ticket status

## Technologies

- Databricks Apps
- Lakebase
- PostgreSQL
- Streamlit
- SQLAlchemy

## Database

Tables

- tickets
- ticket_messages

## Run

streamlit run app.py
